# 🐍 Snake Game using Python & Pygame

🎮 A simple and fun Snake Game built with **Python** and **Pygame**.

---

## ✨ Features

✅ Snake movement using arrow keys  
✅ Random food generation 🍎  
✅ Score counter 📊  
✅ Wall collision detection 🚧  
✅ Self collision detection 💥  
✅ Smooth gameplay 🎮

## ▶️ How to Run

### 1️⃣ Install Pygame

```bash
py -3.13 -m pip install pygame
```

### 2️⃣ Run the Game

```bash
py -3.13 "c:\Users\dell\Desktop\Python Coding\Snake_Game\snake_game.py"
```

Or if your terminal is already inside the project folder:

```bash
py -3.13 snake_game.py
```

⬆️ Up Arrow → Move Up
